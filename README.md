# AI Career Guidance System

## Overview

The AI Career Guidance System is a machine learning-based web application that predicts suitable career paths for users based on their skills, interests, and preferences. The system uses a Random Forest Classifier and provides personalized career recommendations through an interactive Streamlit interface.

## Features

* Career prediction based on user inputs
* Interactive web interface using Streamlit
* Machine Learning model using Random Forest Classifier
* Data preprocessing and feature encoding pipeline
* Real-time prediction results
* User-friendly design
* Cloud deployment using Streamlit Cloud

## Installation

1. Clone the repository
   git clone <repository-link>

2. Navigate to project folder
   cd AI-Career-Guidance-System

3. Install dependencies
   pip install -r requirements.txt

4. Run the application
   streamlit run app.py
